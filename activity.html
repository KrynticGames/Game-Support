Which modes get played?

Visitors are browsers, not verified people. Private browsing, storage clearing, blockers, and disabled statistics affect totals. “Visits” means browser sessions; refreshing can add page views without adding a visit. Starts count actual match starts, including tutorials; selecting a mode alone is counted separately. Completions are linked to matches that started within the selected period. Time counts when the game tab is visible, including menus, and is sent about every 30 seconds. Daily rows use Eastern time. Data is retained for 90 days; no earlier play history can be reconstructed.
