Brain Attack Privacy Policy

Updated October 16, 2026 · Current browser edition

Kryntic Games operates this browser build of Brain Attack. It runs against a computer opponent. It has no account registration, email collection, player chat, private messaging, image upload, online leaderboard or in-game purchases.

Data on your device

The game stores XP, correct/answered totals, best streaks, personal mode/combat records, daily goals, mastered/missed question identifiers, recently seen questions, local question flags, tutorial completion, difficulty and sound preferences in this browser's local storage. Local question flags contain the question, answer, selected issue category and time. No free-form note is collected in the current build; old flag notes are removed from the current session's flags when loaded. Exports remain local files unless you choose to share them yourself.

Network requests and providers

The question bank, sounds and game artwork are embedded in the game. Ordinary gameplay does not fetch questions, send answers or upload progress to a server. The developer activity-statistics script has been removed from this build; the old browser/session tracker identifiers are cleared when it opens. This does not erase historical server-side activity records from earlier versions.

GitHub Pages hosts this website and can process network/request details such as IP addresses and access/security logs. Following a question-source, license or policy link opens the relevant external site, which has its own information practices. If the game is later hosted on a gaming platform, that platform's services and notices apply separately; this browser build contains no separate ad network.

Earlier browser versions sent usage events and random browser/session identifiers to a Railway-hosted service. Those events did not contain typed question notes, question answers or account passwords. The earlier service was configured to clean activity records older than 90 days when processing new events; historical database deletion has not been verified, and this is not a guaranteed deletion deadline. Provider logs and backups have their own settings and retention. Removing the tracker does not certify that every historical copy has already been erased.

Your choices

Progress → Reset progress → Confirm resets XP and personal records. To remove the other local game data, clear site storage in your browser. Local data otherwise remains until overwritten or cleared. Resetting local storage does not delete exported files, hosting logs or provider backups. A dedicated private developer channel for requests about developer-held information has not yet been configured. Public game feedback is not a private privacy-request form, and the developer's responsibilities are not transferred to a host or gaming platform.

Younger players and content

The game contains non-graphic stylized combat and a screened general-knowledge question bank. Content screening is not an official age rating, a guarantee that every question is suitable for every child, or a determination of compliance with children's privacy laws. The current release is not designated as an under-13 children's service. Follow any hosting platform's age rules; the standard CrazyGames platform is for ages 13 and above. No date of birth or parental-consent information is collected by this build.

Changes

This notice describes the version identified above. An iOS release, added advertising, online accounts or new tracking would require another review before those features are offered.
