Browser game activity statistics

These GitHub-hosted browser games send first-party usage events to the developer's existing Railway-hosted server and PostgreSQL database. Events include the game and mode, page opens, play selections, match starts and completions, time with the tab visible, server timestamps, and random browser, session, and match identifiers. No account names, passwords, entered words, question answers, full URLs, or precise location are included in activity events. The hosting provider necessarily handles network information to deliver requests; IP addresses are not stored in the activity database. Browser identifiers are hashed on the server. These statistics are used to understand whether the games are being played, not for advertising or cross-site tracking.

Activity records are retained for up to 90 days. Counts approximate browsers rather than identified people. Automated verification sessions are labeled as tests and excluded from normal dashboard totals.

You can disable activity statistics for both browser games on this browser below. Browser Do Not Track and Global Privacy Control signals are also respected. Clearing site storage resets the preference and random identifiers.
