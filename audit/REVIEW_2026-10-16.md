# Word Havoc and Brain Attack — review of current browser builds

Reviewed October 16, 2026. This is a scoped technical/content review, not legal clearance, an official age rating, a full factual review of the trivia bank, or a guarantee of zero risk.

## What was corrected

- Removed the developer email from the current Help, Privacy and Terms pages for both games and the shared landing page. Historical Git commits and other already-shared copies are not erased by editing current pages.
- Replaced Brain Attack's unfinished privacy draft and incorrect iOS-oriented support text. Added Brain Attack Terms. All six pages describe current browser behavior and identify support/contact limitations.
- Removed Brain Attack's first-party activity tracker and cleared its obsolete local identifiers. Current tested gameplay sends no answers, progress or question flags to a server. Earlier activity records/provider logs have not been erased or verified deleted.
- Removed the free-text question-note field. Flags and optional exports stay on the player's device; the UI explicitly says nobody receives them automatically. No moderation or individual response service is promised.
- Conservatively excluded 471 flagged trivia rows after scanning all question, answer, distractor and explanation fields. 9,675 rows remain (1,665 Easy, 6,493 Medium, 1,517 Expert). Some exclusions are deliberately broad and may include harmless references. This is keyword screening, not comprehensive semantic review or independent fact-checking.
- Strengthened Word Havoc's word/name filter, including common joined/leet name evasions. Ordinary words, scores and multiplayer rules were retained. Filtering can have false positives and misses, and a tampered host client is outside the normal move-validation guarantees.
- Embedded the system Hunspell/SCOWL dictionary copyright and license notices in the self-contained Word Havoc build and added the notice file to the repository.
- Retained Brain Attack's named CC BY-SA trivia credits/change notices and CC0 asset credits. Terms explicitly preserve third-party license permissions.
- Word Havoc's in-game Help/Terms links now use the free static policy copies. No Railway deployment or paid upgrade was performed for this review. The separately deployed Railway support mirror was not updated in this pass; its source is prepared for a later approved deployment.

## Behavior and tests

| Check | Result and limit |
|---|---|
| Player communication | Neither reviewed build has chat, private messaging, voice chat or player image uploads. Brain Attack currently plays against a computer; Word Havoc also offers public online duels. |
| Sensitive device APIs | No camera, microphone, contact-book, geolocation or payment requests were found in either game. |
| Brain Attack storage/network | Browser test: tutorial, real daily trivia, scoring, local flags without notes, confirmed XP reset, blocked-storage play, no external game requests and no JavaScript errors. All 9,675 rows passed the configured content screen and four-distinct-answer structural check. |
| Word Havoc safety | Browser test: malicious remote win/draw/stat/log markup cannot create active page elements or event handlers. Filter tests cover explicit words, evaded names and benign words. |
| Word Havoc gameplay | Local regression: CAT/CATS and cross-word scoring, invalid remote move rejection, match synchronization, reconnect, surrender/rematch, cancellation and Block & Leave. 100 local sockets paired into 50 rooms. This is not a production capacity certification. |
| Word Havoc saves | Simulated CrazyGames SDK tests pass profile display, account isolation, record reset confirmation/cancel, save-failure messages and no secret/rack uploads. Actual CrazyGames cloud saves still need platform-preview confirmation. |
| Policy pages | All six current static pages: no developer email/mailto links or submission forms, working internal navigation, mobile/desktop layout and no JavaScript errors. |
| Visual content | Reviewed mobile gameplay uses stylized soldiers/missiles without visible gore. This is not a formal PEGI/ESRB rating or certification for all children. |

## Decisions that cannot honestly be marked complete

1. **Private privacy-request contact:** neither game has a dedicated private developer channel. Self-service local resets cannot delete hosting logs/backups. Public platform feedback is not presented as a substitute. A suitable operational channel remains necessary before claiming that privacy obligations are fully handled; no unmonitored form was added and no response service is falsely promised.
2. **Audience and platform review:** standard CrazyGames is for ages 13+ and requires PEGI-12-compliant content. These builds have not been certified as under-13 children's services. Simple word/trivia mechanics alone do not determine COPPA applicability. Platform ads, SDK behavior and final store age questionnaires require platform-specific review.
3. **Name and rights clearance:** an existing Google Play trivia/shooter uses “Brain Attack: Dodge & Quiz.” That is a name-overlap finding, not a finding of infringement or a legal clearance. No comprehensive trademark/name search or full chain-of-title audit was completed, and the game has not been renamed. Source-page licenses were verified for the named trivia/audio/model assets; that is not a guarantee against every third-party claim or proof of every embedded image's provenance.
4. **Historical data:** legacy Word Havoc account/statistics tables/endpoints and earlier activity/report logs exist in the relay source. Whether they contain historical user data and whether any such data has been deleted were not verified. Current local resets do not promise to erase them.
5. **Scope:** iOS/App Store packages, every possible browser/device, all 9,675 factual answers, malicious-host cheating resistance, the hosting platform's ads and arbitrary future changes are outside the completed checks. No “everything is legally safe” claim is made.

These are concrete limits of the review; they do not establish that a claim or lawsuit exists.
